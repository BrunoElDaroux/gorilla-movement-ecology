================================================================================
  DATASET DOCUMENTATION - Mountain Gorilla GPS Movement Data (Virunga Massif)
================================================================================

FILE: data/raw/gorilla_gps_data.csv
GENERATED BY: python src/data_generator.py
REAL DATA SOURCE: Movebank (https://www.movebank.org)

COLUMN DESCRIPTIONS:
  timestamp    - GPS fix time (10-min intervals, 06:00-14:00 daily)
  group_id     - Gorilla group name (Susa/Hirwa/Amahoro/Umubano/Pablo/Kwitonda)
  latitude     - WGS84 decimal degrees (South = negative)
  longitude    - WGS84 decimal degrees (East = positive)
  altitude_m   - Elevation in meters (Virunga: 2200-4500m)
  observer_id  - Field researcher ID (anonymized)
  group_size   - Total individuals in group
  silverbacks  - Number of silverback males
  nest_site    - TRUE if morning nest departure fix (06:00)
  date         - Calendar date
  day_of_year  - Julian day (1-365)
  hour         - Hour of fix (6-14)
  habitat_type - Vegetation: montane_forest/bamboo_zone/subalpine_zone/mixed
  season       - dry_season/long_rains/short_rains

HOW TO GET REAL DATA:
  1. Movebank: https://www.movebank.org (free account)
     Search "Gorilla beringei beringei" -> Download CSV
  2. GBIF: https://www.gbif.org/species/2889338
  3. Dryad: Search "mountain gorilla ranging"

COORDINATE SYSTEM: WGS84 (EPSG:4326)
PROJECTION FOR ANALYSIS: UTM Zone 36S (EPSG:32736)
